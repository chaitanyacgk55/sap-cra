1 Project details

Files will be saved to uploads/<project-name>/. Spaces become hyphens.
Comma-separated aliases. All occurrences are redacted as [CLIENT] in the PDF & Excel reports (case-insensitive, whole-word). Emails, IPs and JWT tokens are always masked.

1a Functional Design (optional)

Upload the Functional Design — only .doc or .docx files are accepted. The agent runs the code review and the Accenture Suggested Approach analysis in parallel and writes both into the report. If the suggested approach differs from the one followed in the uploaded code, it's highlighted on page 1 of the Excel.

1b Client suggestions (optional)

Upload a .txt, .md, .csv or .xlsx file with client-specific review rules (project naming, auth policies, allowed/forbidden APIs, etc.). These rules take priority over the baseline review for the sections they cover — findings sourced from them are highlighted with a different color in the Excel & PDF reports. Baseline stays unchanged for everything else.

2 Add files

Click to pick a project folder, or drop a folder / ZIP / TAR here

Supported: folders, .zip, .tar, .tar.gz, .tgz — the whole tree is uploaded (webapp/, srv/, db/, abap/...).

3 Run the review

Click Review to trigger /sap-code-reviewer on the local server. The server runs the Claude agent, writes findings JSON, and generates the Excel report — all in one step.

Deterministic caching: results are pinned to the exact contents of your upload & the agent instructions. Re-clicking Review on an unchanged upload returns the identical findings. Change any source file (or update the agent) to trigger a fresh review.
